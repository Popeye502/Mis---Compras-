## ✨ Características

- ✅ **Agrega productos** rápidamente a tu lista
- ✓ **Marca como comprado** con un solo toque
- 🗑️ **Elimina** artículos que ya no necesitas
- 📊 **Contadores en tiempo real**: Total, Comprados, Pendientes
- 💾 **Guardado automático** en tu dispositivo (localStorage)
- 📱 **Instalable como App** en Android y iOS
- 📶 **Funciona SIN internet** (Service Worker)
- 🎨 **Diseño moderno** con efecto Glassmorphism
- 🌙 **Fondo profesional** con imagen de supermercado

---

## 📱 Cómo instalar en tu celular

### Android (Chrome)
1. Abre la URL de la app en **Chrome**
2. Toca los **3 puntitos** ⋮ del menú
3. Selecciona **"Instalar app"** o **"Agregar a pantalla de inicio"**
4. ¡Listo! Tendrás el ícono en tu pantalla

### iPhone (Safari)
1. Abre la URL en **Safari**
2. Toca el botón de **Compartir** 📤
3. Selecciona **"Agregar a pantalla de inicio"**
4. Confirma y ya tendrás la app

---

## 🚀 Cómo usar

1. **Escribe** el producto en el campo de texto
2. Toca el botón **+** o presiona **Enter**
3. Cuando lo compres, toca el botón **✓** para marcarlo
4. Para eliminarlo definitivamente, toca **✕**
5. Usa **"Limpiar toda la lista"** para empezar de nuevo
